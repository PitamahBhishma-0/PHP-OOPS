# Topic 3F  Exception Handling

## Key Concepts
- `try` / `throw` / `catch` blocks
- `finally` block (always executes)
- Custom exception classes (`extends Exception`)
- `getMessage()`, `getLine()`, `getFile()`, `getCode()`
- Multiple `catch` blocks for different exception types
