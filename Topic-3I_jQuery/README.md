# Topic 3I  jQuery: Elements, Show/Hide, jQuery UI

## Key Concepts
- jQuery `$()` function and CSS selectors
- `$(document).ready()` — DOM ready handler
- Method chaining
- `.hide()` / `.show()` / `.toggle()` — instant and animated
- `.fadeIn()` / `.fadeOut()` / `.fadeToggle()`
- `.slideUp()` / `.slideDown()` / `.slideToggle()`
- `.append()` / `.remove()` / `.css()` for element manipulation
- jQuery UI widgets: `datepicker`, `dialog`
