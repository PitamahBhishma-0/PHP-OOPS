# Topic 3H  AJAX with PHP + MySQL

## Key Concepts
- Live search with AJAX + MySQL
- Prepared statements (`mysqli_prepare()`) to prevent SQL injection
- `mysqli_stmt_bind_param()`, `mysqli_stmt_execute()`
- `mysqli_fetch_all(MYSQLI_ASSOC)` for JSON output
- `php://input` for reading JSON POST body
- Dynamic DOM updates from server data
