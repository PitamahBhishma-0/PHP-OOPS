# Topic 3E  Static Members

## Key Concepts
- Static properties (shared across all instances)
- Static methods (callable without `new`)
- `self::` vs `static::` (early vs late binding)
- Scope Resolution Operator `::`
- Class constants (`const`)
- No `$this` inside static methods
