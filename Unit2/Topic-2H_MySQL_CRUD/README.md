# Topic 2H  MySQL CRUD: INSERT, SELECT, UPDATE, DELETE

## Key Concepts
- `INSERT INTO` — adding new records
- `SELECT` — retrieving records
- `UPDATE` — modifying existing records
- `DELETE` — removing records
- `WHERE` clause for filtering
- Displaying results in HTML tables with PHP
- `mysqli_query()` for executing all SQL statements
- `mysqli_affected_rows()` to check operation success
