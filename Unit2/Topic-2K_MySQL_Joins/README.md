# Topic 2K  MySQL Joins: INNER, LEFT, RIGHT

## Key Concepts
- `INNER JOIN` — only matching records from both tables
- `LEFT JOIN` — all records from left table, NULLs on right
- `RIGHT JOIN` — all records from right table, NULLs on left
- `ON` clause for join conditions
- Foreign key relationships between tables
- Joining with `WHERE` for filtering
