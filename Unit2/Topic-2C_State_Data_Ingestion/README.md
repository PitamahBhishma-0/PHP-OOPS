# Topic 2C  State & Data Ingestion: Form Handling, GET, POST

## Key Concepts
- HTML forms with `method="GET"` and `method="POST"`
- `$_GET` superglobal (URL parameters)
- `$_POST` superglobal (form body data)
- `$_REQUEST` (combined GET/POST)
- `htmlspecialchars()` for sanitizing output
- Form submission detection with `$_SERVER["REQUEST_METHOD"]`
