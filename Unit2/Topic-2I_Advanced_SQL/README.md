# Topic 2I  Advanced SQL: Aggregate Functions, GROUP BY, ORDER BY

## Key Concepts
- `COUNT()`, `AVG()`, `SUM()`, `MIN()`, `MAX()` aggregate functions
- `GROUP BY` for grouping records
- `ORDER BY ASC / DESC` for sorting
- `HAVING` clause for filtering grouped data
- Alias with `AS` for readable output
- Fetching aggregate results with `mysqli_fetch_assoc()`
