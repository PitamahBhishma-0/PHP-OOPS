# Topic 2F  Session & Cookie Management

## Key Concepts
- `session_start()` — must be before any output
- `$_SESSION` superglobal for server-side persistent data
- Session visit counters and user data
- `setcookie()` — name, value, expiry, path
- `$_COOKIE` superglobal
- Cookie expiry with `time() + seconds`
- Fallback values when cookies are not set
