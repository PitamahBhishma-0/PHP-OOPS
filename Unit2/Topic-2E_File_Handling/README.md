# Topic 2E  File Handling: Read, Write & File Uploading

## Key Concepts
- `fopen()`, `fwrite()`, `fgets()`, `fclose()` for file operations
- `file_put_contents()` and `file_get_contents()` (simplified)
- `FILE_APPEND` flag for appending to files
- `move_uploaded_file()` for file uploads
- `$_FILES` superglobal
- `is_dir()`, `mkdir()` for directory management
- `htmlspecialchars()` for safe file content display
