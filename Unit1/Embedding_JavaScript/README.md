# Embedding JavaScript: Inline, Internal & External

## Key Concepts
- Inline JavaScript (event attributes like `onclick`)
- Internal (embedded) JavaScript inside `<script>` tags
- External JavaScript via `<script src="...">`
- `async` and `defer` attributes
- The `<noscript>` tag
