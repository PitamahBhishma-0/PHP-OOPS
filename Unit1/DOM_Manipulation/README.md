# Document Object Model (DOM): Selection & Manipulation

## Key Concepts
- Selection: `getElementById`, `querySelector`, `querySelectorAll`
- Content: `innerHTML`, `textContent`
- Styling: `style.property`, `classList`
- Nodes: `createElement`, `appendChild`, `remove`
